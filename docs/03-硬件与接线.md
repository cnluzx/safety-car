## 2. ESP32-S3 引脚分配

| 功能 | GPIO | 接到驱动板 |
| --- | --- | --- |
| 左电机 PWM | 1 | ENA / PWMA |
| 左电机 IN1 | 2 | AIN1 |
| 左电机 IN2 | 42 | AIN2 |
| 右电机 PWM | 4 | ENB / PWMB |
| 右电机 IN1 | 5 | BIN1 |
| 右电机 IN2 | 6 | BIN2 |
| 水平扫描舵机 | 8 | 信号线 |
| 高位俯仰舵机 | 3 | 信号线 |
| 左编码器 A / B | 36 / 35 | E1A / E1B |
| 右编码器 A / B | 38 / 37 | E2A / E2B |

方向修正宏在 `lower-ESP/main/main.c`：

```c
#define MOTOR_LEFT_REVERSE   1   // 左侧电机接线反了，取反
#define MOTOR_RIGHT_REVERSE  0
```

**换车第一件事**：手动发 `@|1|20|0|0#` 看两轮是不是都往前。若某轮反了，改这两个宏，别改接线。

## 3. PWM 参数

| | 频率 | 分辨率 | 定时器 | 通道 |
| --- | --- | --- | --- | --- |
| 电机 | 500 Hz | 13 bit（0–8191） | TIMER_0 | CH0 左 / CH1 右 |
| 舵机 | 50 Hz | 13 bit | TIMER_1 | CH2 水平 / CH3 俯仰 |

舵机角度→占空比：`duty = 204 + angle × (1024−204) / 180`。
若舵机行程对不上（打角不到 180°），用指令 19 直接给脉宽（400–2600 µs）找端点，再回来调公式。

## 4. 供电与干扰（血泪经验）

1. **上位机与下位机必须共地**，否则串口偶发丢帧、RFID 乱码。
2. **舵机单独供电**。两个舵机同时动会拉低 5V，导致 ESP32 复位、摄像头掉线。
   下位机为此把舵机动作做成"2° 一步、每步 6–10 ms"的缓动（`servo_slow_scan`），不要改回瞬时跳变。
3. 电机电源与逻辑电源分开走线，电机线远离编码器信号线（编码器已加 10 µs 毛刺滤波，但布线更管用）。
4. 摄像头尽量用带屏蔽的短线；两路 USB 摄像头抢带宽时把分辨率降到 640×480 更稳。

## 5. 串口设备对应关系

| 设备 | 默认 | 环境变量 | 说明 |
| --- | --- | --- | --- |
| ESP32 底盘 | `/dev/ttyUSB0` | `CHASSIS_PORT` | ESP32-S3 的 USB（CDC 或 CH340） |
| RFID 读卡器 | `/dev/ttyACM0` | `RFID_PORT` | 常见为 CH340/CP210x |

查设备：

```bash
ls -l /dev/serial/by-id/     # 有稳定软链接，插拔不变名
v4l2-ctl --list-devices      # 摄像头编号
```

> 原开发机用的是 FTDI 转串口（`usb-FTDI_FT232R_USB_UART_...`）。换线后这个名字会变，
> 所以代码里默认值统一改成了 `/dev/ttyUSB0`，特殊设备用环境变量覆盖。

## 6. 摄像头编号

| 用途 | 默认 | 环境变量 | 说明 |
| --- | --- | --- | --- |
| 巡线（低位） | 2 | `NAV_CAMERA` | 朝下看路面，需要 `NAV_CAMERA_FLIP=-1` 翻转 |
| 涵洞（高位） | 0 | `CULVERT_CAMERA` | 装在云台上，一般不用翻转 |

编号每次开机可能变（`/dev/video0`、`video2`…），上场前务必确认。
