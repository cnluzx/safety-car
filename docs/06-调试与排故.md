# 调试与排故

## 1. 分层定位法（最重要的一条）

车出问题，先判断是**哪一层**的锅，不要一上来就改巡线参数：

```
现象
 ├─ 车完全不动              → 下位机 / 供电 / 串口
 ├─ 会动但动作不对（转不够、走过头） → 下位机标定参数
 ├─ 巡线画龙 / 冲出赛道      → 视觉 PID / 模型帧率 / 光照
 ├─ 路口识别错（该转不转）    → line_detect 路口判定 / junction_mode
 ├─ 到了涵洞不停            → Culvert_detect 阈值 / 视觉触发链路
 └─ 规划路线奇怪 / 漏路      → topo_map / navigator（先 --plan-only 验证）
```

**先离线，后上线**：规划问题用 `--plan-only`，视觉问题用 `tests/` 里对应的单点脚本，
底盘问题用串口助手手发指令。三层各查一遍，比整车瞎试快一个数量级。

## 2. 症状 → 原因 → 处理

| 症状 | 可能原因 | 怎么确认 / 怎么修 |
| --- | --- | --- |
| 上位机启动报"无法打开底盘串口" | 设备名不对 / 被别的进程占用 | `ls -l /dev/serial/by-id/`；设 `CHASSIS_PORT`；`lsof /dev/ttyUSB0` |
| 串口能发但车不动 | 下位机没上电 / 电机电源没开 / 急停锁死 | 串口监视看有没有 `Link lost ... motors locked`；发任意指令解锁 |
| 车一动就重启（ESP32 复位） | 舵机抢电，5V 掉压 | 舵机独立供电；确认缓动函数没被改成瞬时跳变 |
| 转向角度总是不对 | `ENC_TURN_PER_V2` 没标定 / 电压低转速不足 | 手发 `@\|3\|1\|90\|0#` 量实际角度，按比例改系数 |
| 路口停车位置偏 | `ENC_FWD_TO_CENTER` 不对 | 手发 `@\|2\|1\|90\|0#` 观察前冲距离 |
| 巡线左右摇摆（画龙） | `KP` 太大 / `KD` 太小 / 帧率低 | 降 `FULL_MAP_KP`，升 `FULL_MAP_KD`；`LINE_DEBUG=1` 看 FPS |
| 巡线总是偏一侧 | 摄像头没装正 / `NAV_CAMERA_FLIP` 错 | 用 `tools/camera_lower_left.py` 看原始画面 |
| 该转的路口直行了 | 路口判定没触发（mask 里看不到横向路） | 降 `junction_top_ratio` 附近阈值；确认 `junction_mode` 是否应为 `L` |
| 同一路口连续触发多次 | 视觉帧还停在路口 | 主程序有 `_cross_event_latched` 锁存，改逻辑时别删 |
| 到涵洞不停车 | 亮度/纹理阈值不匹配当前光照 | 单独跑 `python3 src/Culvert_detect.py --camera 0` 看判定值 |
| 停在涵洞不动了 | 在等 `Y_L`/`Y_R` 但下位机没发 | 串口监视看有没有 `Y_START`；没有就是指令 10 没收到 |
| 侦查完不动 | 电机还在锁 / 已失联 | 等 `Y_END`；`g_link_lost` 需要发有效指令解锁 |
| 拍照没保存 | 目录不可写 | 检查 `CULVERT_YOLO_SAVE_DIR`（默认 `<项目根>/logs/culvert_yolo`） |
| 语音不响 | 没有 sound 目录 / 音频设备忙 | 放音频到 `upper-PI/sound/`；`SOUND_DIR` 可覆盖 |
| 小屏不亮 / 启动报 Tk 错 | 没有 X display | OLED 非必需，无桌面环境会自己降级，不影响跑 |
| 模型加载失败 | rknnlite 版本不匹配 / 模型路径 | `python3 -c "from rknnlite.api import RKNNLite"`；看报错里的路径 |
| `test_yolo.py` 跑不起来 | 缺 `pose_4pt_*.rknn` | 已知缺失，见 models/README.md |

## 4. 我们踩过的坑（现场版）

1. **`@` 应答串位**：上一动作的 `@` 被当成本次完成，导致"还没转完就发下一条"，
   表现是转向角度忽大忽小。修法是发指令前清缓冲 + 50 ms 最小延迟 + 150 ms 去抖。
2. **指令 4 误用**：以为 `turn_all(90)` 是转 90°，结果车跑了一整套动作序列。
3. **`mini_adjust` 不生效**：传的 `v1=10`，而下位机只认 `v1==15`，于是变成持续前进。
4. **双摄像头抢 USB 带宽**：1280×720 两路同时开，巡线掉到 12 FPS，画龙。
   把巡线降到 640×480 后稳定 30 FPS。
5. **涵洞出口误判路口**：出口处 mask 突然变宽，被判成十字路口。
   后来加了 `TUNNEL_EXIT` 判定剖面才稳。
6. **调试断点导致停车**：在 Python 里打断点，1.5 s 后下位机自己停车锁死，
   以为是程序 bug，其实是失联保护在正常工作。

# 2. 规划（不碰硬件）
cd upper-PI && ./run.sh --plan-only

# 3. 单点（挑改到的那个模块）

# 4. 整车低速跑

# 5. 正常速度
./run.sh
