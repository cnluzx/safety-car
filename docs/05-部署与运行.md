# 部署与运行

## 1. 下位机（ESP32-S3）

### 环境

- ESP-IDF **v5.5.2**（其他 5.x 大概率也能编，但引脚配置宏与驱动 API 有变动风险）
- Python 3.10+（idf.py 自身依赖）
- 目标芯片：`esp32s3`，2 MB Flash，无 PSRAM

### 编译烧录

```bash
cd lower-ESP
idf.py set-target esp32s3      # 首次；会生成 sdkconfig
idf.py build
idf.py -p /dev/ttyUSB0 flash monitor
```

看到下面这行说明固件起来了：

```
I (xxx) ESP32_CHASSIS: Chassis System Online.
```

### 最简自检（不用上位机）

任意串口工具，115200，发送：

| 发送 | 期望 |
| --- | --- |
| `@|1|20|0|0#` | 两轮低速前进 |
| `@|5|0|0|0#` | 立即停车，回 `@` |
| `@|3|1|90|0#` | 原地顺时针转 90°，约 0.6 s 后回 `@` |
| `@|9|90|0|0#` | 水平舵机转到 90° |
| `@|14|0|0|0#` | 回 `E:l,r` 和 `@` |

`@|1|20|0|0#` 之后如果车一直走不停，是正常的——指令 1 是 PWM 直控，需要手动发 `@|5|0|0|0#`。

## 2. 上位机（香橙派 5 Pro / RK3588）

### 系统依赖

```bash
sudo apt update
sudo apt install -y python3-pip python3-opencv python3-tk v4l-utils
# 音频（语音播报用）
sudo apt install -y alsa-utils
```

### Python 依赖

```bash
pip install -r requirements.txt
```

**`rknnlite` 是最容易卡住的一步**：它不在 PyPI，必须用 Rockchip 官方 wheel。

```bash
# 从 https://github.com/airockchip/rknn-toolkit2 的 rknn-toolkit-lite2/packages/ 下载
# 文件名形如 rknn_toolkit_lite2-2.x.x-cp310-cp310-linux_aarch64.whl
pip install rknn_toolkit_lite2-*.whl

# 验证
python3 -c "from rknnlite.api import RKNNLite; print('rknn ok')"
```

注意 wheel 的 cp 版本必须匹配板上的 Python（`python3 -V`）。

### 配置设备

```bash
cd upper-PI
cp .env.example .env
vi .env          # 改串口和摄像头编号
```

```bash
ls -l /dev/serial/by-id/    # 找底盘和 RFID
v4l2-ctl --list-devices     # 找两个摄像头
```

### 运行

```bash
./run.sh --plan-only    # ① 离线规划，验证地图/规划器（不碰硬件）
./run.sh                # ② 整车运行
```

启动后会依次看到：

```
[READY] 摄像头=2 串口=/dev/ttyUSB0 巡线速度=9 障碍识别=ON
[FULL MAP TEST] 规划节点数=xxx，需覆盖道路=xx
[FULL MAP TEST] 路线: START_AREA -> J_TOP -> N1 -> ...
[READY] 1 秒后启动...
[LINE] 状态=LINE 偏差=  3 目标=N1 路口模式=NORMAL
```

### 退出

`Ctrl+C` 一次即可。程序会依次：停车 → 释放相机 → 落盘侦查照片 → 关闭串口。
若进程被杀，下位机 1.5 s 后自动停车（失联保护）。

## 3. 上线前检查清单（照着打勾）

- [ ] 下位机 `idf.py build` 无警告项异常，上电打印 `Chassis System Online.`
- [ ] 手发 `@|1|20|0|0#` 两轮都向前（不向前就改 `MOTOR_*_REVERSE`）
- [ ] 手发 `@|3|1|90|0#` 实测转角接近 90°（否则重标 `ENC_TURN_PER_V2`）
- [ ] `./run.sh --plan-only` 路线覆盖所有道路、最后回到 `START_AREA`
- [ ] 两个摄像头编号正确，画面方向正（`NAV_CAMERA_FLIP`）
- [ ] RFID 读卡点亮（`PYTHONPATH=src python3 src/rfid.py` 单独测）
- [ ] 巡线 ≥ 25 FPS（`LINE_DEBUG=1` 看调试窗口左上角）
- [ ] 急停可达：随时能按 `Ctrl+C`，或直接断电
- [ ] 电池电压充足（舵机同时动作会掉压，电压低时先换电再排故）

## 4. 场地快速标定（换场地必做）

| 要标什么 | 改哪里 | 怎么标 |
| --- | --- | --- |
| 每度转角脉冲 | `lower-ESP/main/main.c: ENC_TURN_PER_V2` | 发 `@|3|1|90|0#`，量实际角度，按比例调 |
| 路口前冲距离 | `ENC_FWD_TO_CENTER` | 发 `@|2|...`，看是否停在路口中心 |
| 差速巡线手感 | `FULL_MAP_KP` / `KD` / `MAX_ANGLE` | 用 `tests/test_line.py --drive` 单独调 |
| 涵洞判定灵敏度 | `CULVERT_BRIGHTNESS_THRESHOLD` | 用 `src/Culvert_detect.py` 自测模式 |
| 障碍 ROI | `OBSTACLE_ROI_*` | `OBSTACLE_DEBUG=1` 看框选区域 |
